# AI Resource Directory Chrome Extension

A comprehensive Chrome extension that provides easy access to AI tools, platforms, and learning resources.

## Features

- 🔍 Search and filter AI resources
- ⭐ Save favorite resources
- 🌓 Dark/Light mode support
- 📱 Responsive design
- 🔄 Recently visited tracking
- 📶 Offline access
- 🏷️ Resource categorization and tagging

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/ai-resource-directory.git
cd ai-resource-directory
```

2. Install dependencies:
```bash
npm install
```

3. Build the extension:
```bash
npm run build
```

4. Load the extension in Chrome:
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select the `dist` directory

## Development

- Start development server:
```bash
npm run dev
```

- Run tests:
```bash
npm test
```

- Run tests with coverage:
```bash
npm run test:coverage
```
