## [1.2.0] - 2024-12-02

### Added
- Enhanced keyboard shortcuts for quick actions
- Context menu integration
- Offline support via Service Worker
- Usage analytics tracking
- Advanced configuration system with feature flags
- Toast notification system
- Accessibility improvements (ARIA labels, semantic HTML)
- Recently visited tracking
- TypeScript support
- Comprehensive testing infrastructure with Vitest
- JSDoc documentation generation
- Code quality tools (ESLint, Prettier)

### Changed
- Updated to Chrome Manifest V3
- Improved dark mode implementation
- Enhanced search functionality
- Optimized performance with caching strategies

### Fixed
- Various bug fixes and stability improvements

## [1.1.0] - 2024-11-15

### Added
- Dark mode toggle
- Category filtering
- Favorites/bookmarks system
- Basic search functionality

### Changed
- Improved UI design and layout
- Enhanced resource card styling

### Fixed
- Search input focus issues
- Filter state persistence

## [1.0.0] - 2024-10-01

### Added
- Initial release
- Core directory functionality
- Basic resource listings:
  - AI Tool Directories (There's An AI For That, Futurepedia)
  - Interactive AI Models (ChatGPT, Claude)
  - Development Resources (Hugging Face, Papers with Code)
  - Learning Resources (Fast.ai, DeepLearning.AI)
- Basic search and filtering
- Responsive design
- Chrome extension infrastructure

## Upgrade Notes

### Upgrading to 1.2.0
- No breaking changes
- All existing data and settings will be preserved
- New features are opt-in via configuration

### Upgrading to 1.1.0
- Dark mode preference will reset to system default
- Favorites will be preserved
