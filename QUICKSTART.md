# AI Resource Directory - Quick Start Guide

Welcome to AI Resource Directory! This guide will help you get started quickly.

## 🚀 Getting Started in 30 Seconds

1. **Install the Extension**
   - Click the extension icon in Chrome toolbar
   - Or use keyboard shortcut: `Ctrl+Shift+A` (Windows/Linux) or `Cmd+Shift+A` (Mac)

2. **Browse Resources**
   - Scroll through categorized AI tools
   - Click any link to visit the AI tool website

3. **Search for Tools**
   - Type in the search box at the top
   - Results filter in real-time

That's it! You're ready to explore AI tools.

## 🎯 Key Features

### Search & Filter
- **Quick Search**: Type to find tools instantly
- **Category Filter**: Use dropdown to filter by category (Directories, Models, Development, Learning)
- **Combined**: Search and filter work together

### Favorites ⭐
- **Add Favorite**: Click the star (☆) on any tool card
- **View Favorites**: Click the star button in the header
- **Quick Access**: Keyboard shortcut `Ctrl/Cmd+Shift+F`

### Dark Mode 🌓
- **Toggle**: Click the moon icon in header
- **Auto-Save**: Your preference is remembered
- **System Sync**: Respects your system theme

### Recently Visited 📝
- **Auto-Track**: Visited tools appear in "Recently Visited"
- **Quick Return**: Easy access to tools you've checked out

## ❓ Common Questions

### How do I add a tool to favorites?
Click the star (☆) icon on any tool card. It will turn filled (★) to indicate it's favorited.

### Can I use this offline?
Yes! The extension caches resources for offline access. You may see limited functionality when offline.

### How often is content updated?
The extension updates automatically. New tools are added regularly.

### Can I suggest a tool to add?
Yes! Visit our [GitHub repository](https://github.com/VpkDevs/ai-resource-directory) and create an issue or pull request.

### Is my data private?
Yes! All data (favorites, settings) is stored locally on your device. Nothing is sent to external servers.

### How do I export my favorites?

## 🆘 Troubleshooting

### Extension not working?
1. Refresh the extension (right-click icon → Reload)
2. Check Chrome version (minimum v88 required)
3. Disable and re-enable the extension

### Can't find a specific tool?
1. Try different search terms
2. Check all categories
3. Tool might not be added yet - suggest it!

### Dark mode not saving?
1. Check browser storage permissions
2. Clear extension storage and try again
3. Report issue on GitHub

### Links not opening?
1. Check popup blocker settings
2. Ensure external links permission is granted
3. Try right-click → Open in new tab
