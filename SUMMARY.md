## About the AI Resource Directory App

**AI Resource Directory** is a Chrome browser extension that serves as a comprehensive directory of AI tools, platforms, and resources.

### Current Features
- Search and filter AI resources
- Favorites/bookmarks system
- Dark mode support
- Recently visited tracking
- Offline support
- Keyboard shortcuts
- 10+ AI tools across 4 categories

### Tech Stack
- Chrome Extension (Manifest V3)
- Vanilla JavaScript/TypeScript
- Vite (build tool)
- Vitest (testing)
- ESLint & Prettier
