# Project Overview: AI Resource Directory Chrome Extension

## Purpose
The AI Resource Directory is a Chrome extension designed to provide users with easy access to a comprehensive collection of AI tools, platforms, and learning resources. It aims to enhance user experience by offering features such as search and filter capabilities, offline access, and user preferences.

## Features
- **Search and Filter**: Users can search and filter AI resources based on categories and tags.
- **Favorites**: Users can save their favorite resources for quick access.
- **Dark/Light Mode**: The extension supports theme switching for user preference.
- **Responsive Design**: The UI is designed to be responsive across different devices.
- **Offline Access**: Users can access resources even when offline, thanks to caching strategies.
- **Notifications**: Toast notifications provide feedback on user actions.
- **User Preferences**: Users can customize settings such as maximum recent items and default categories.

## Current Implementation
The project is implemented using TypeScript and follows best practices for web development. It includes:
- A well-structured codebase with utility functions for various operations.
- A service worker for offline functionality and caching.
- A comprehensive testing suite using Vitest to ensure code quality and reliability.
